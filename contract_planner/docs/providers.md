# GMS 모델과 사용량

2026-11-20 기준 GMS는 GPT-6 Astra → GPT-6 Sol → Claude Fable 5.1 → Claude Opus 5.5 순으로 요청합니다. 각 모델에 짧은 입력을 보내 실제 응답을 확인했습니다. 기본 판독은 GPT-6 Astra가 맡으며, 로컬 앱에 나온 처리 모델은 요청 결과나 실행 로그에서 확인할 수 있습니다. [SSAFY GMS](https://gms.ssafy.io/web/)

- 첨부 매매계약서를 GPT-6 Astra로 판독해 매매대금, 계약금, 2차 중도금, 잔금의 숫자 표기와 지급일을 확인했습니다. 보고서 초안에서는 말소 약정, 시설 인수, 공과금 정산 요청을 구체화했습니다.
- 법률 검색은 2회차 수집본에서 후보를 짧게 추리고 `text-embedding-3-large`로 순위를 정합니다. 특약 질문에서 GPT-6 Astra가 수집본의 민법 제623조를 인용하는 것을 확인했습니다. GMS 임베딩 호출이 실패하면 기존 로컬 BGE-M3 색인을 사용합니다.
- 상대 날짜는 GMS가 요청에서 문구를 선택하고 애플리케이션이 달력에 대입합니다. 공휴일·가용 시간·재계획은 규칙과 공개 도구로 계산합니다.

`/api/usage`는 프로젝트의 GMS 및 Anthropic 사용량을 별도로 집계합니다. 앱에 기록된 입력·출력 토큰은 GMS 포털의 크레딧과 별개입니다. 모델 접근 확인에 쓴 단독 호출은 앱 집계와 별도입니다.

앱의 누적 토큰 차단을 제거했습니다. 응답에서 돌려준 입력·출력 토큰은 계속 기록합니다. 요청 가능 여부는 SSAFY GMS의 계정 크레딧과 서비스 상태에 따릅니다.
